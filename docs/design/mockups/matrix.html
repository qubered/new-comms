Talk (phone)

What the Director's panel looks like. Six keys, a Reply key, and the feeds with no key listed underneath.

Keys are the T cells in this panel's row of the matrix, in the order set in Ports. A key's heading is the port it talks to: a conference, a person, a group, an IFB or a 4-wire out.

Listen keys (a key with function "listen") show dimmed and toggle monitoring of a source.

Reply lights with the name of whoever last talked to this panel directly, and talks back to them. It does not count toward six. Its mode is set per panel.

Levels adjusts the operator's own volume for every source heard: the six keys and the feeds underneath. The Manager's crosspoint gain sits beneath that.
