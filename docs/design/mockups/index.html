one comms system

Interactive mockups for the Talk app (what a crew member holds) and the Manager app (what the show's comms person runs). Everything in them is example data. Open Talk on your phone; the keys behave like the real thing.

Try in Talk

  • Pick Stage Manager. Director asks for a PIN: 1234.
  • Production is Auto: tap it and it latches, hold it and it releases when you let go.
  • Cameras is PTT: hold to talk. Director is Latch: tap on, tap off.
  • Program is a PGM feed you can switch off for yourself. Announce is always on.
  • Levels swaps every key for its slider. Nothing can key while you mix.
  • Mic kills your mic everywhere and drops any latched key.
  • Menu ≡ simulates a talker or a dropped connection.

Try in Manager

  • Live is a matrix: rows are packs, columns are channels. Red cells are keyed right now. It updates on its own.
  • Packs edits one pack: PIN, channel assignment, and the key behavior for each channel.
  • Channels shows the Direct-line rule (exactly two packs) and the PGM feed rule (a hardware node is the source).
  • Hardware nodes lists bridges as they register. Nothing to pair.

Design decisions

  • Keys look like keys. Each channel is a backlit tile with a tally strip along the top in its channel color. Keyed turns the whole key red and shows your own mic level. Red means one thing only: your mic is hot.
  • Who's talking is on the key. Every real intercom shows audio presence per channel (Unity, Green-GO). The tile shows the talker's name and a green level so you know a channel is live without hearing it first.
  • Mixing is a separate mode. Agent-IC guards against accidental keying with swipe-to-latch. Here, Levels replaces keys with sliders, so there is no way to key a channel while adjusting it.
  • Pack labels are tape. Packs are named on off-white label strips, the way every beltpack on a rack is labeled in gaffer tape. It's the one decorative move, and it doubles as the "you are this pack" marker.
  • The Manager opens on a matrix. Riedel Artist, Eclipse and every serious intercom frame are configured as a crosspoint grid. Packs × channels shows assignment and live state in one view, and edit mode makes the same grid the assignment tool.
  • Type is condensed and industrial. A condensed grotesk for key labels (reads like panel engraving), a plain grotesk for everything else, a monospace for levels, modes and IDs.
  • Dark by design, not by default. Backstage, in a truck, at FOH. Single theme, high contrast, colors reserved for meaning.

What this adds to the spec

Things the mockups needed that the design spec doesn't say yet. Each one is small; none changes the architecture.

Mic kill
A pack-wide mic off that drops every keyed channel and blocks keying until turned back on. Every soft panel has one. One extra boolean in the pack's live state.
Talker on key
The Talk app shows who is keyed on each channel. Already available from the SSE keyed state; just needs the pack name resolved client-side.
Levels mode
Per-channel volume is edited in a separate Levels mode, not from a control inside the key. Prevents accidental keying while mixing.
Direct names
A Direct channel has one name in the Manager, but each side's key shows the other person's pack name.
Connecting state
Keys are disabled while connecting or reconnecting, and any latched key drops on connection loss. A visible banner says why keys are off.
Hardware in picker
Hardware packs are listed on the picker but not selectable, so people can see the bridges exist without being able to become one.
Matrix edit
The Manager's Live matrix doubles as the assignment editor (click a cell to assign and cycle key behavior). The Packs editor stays for PIN, names and levels.
