---
title: Glossary
---

| Term | Meaning in new-comms |
| --- | --- |
| Always | Standing trigger active while its physical source is connected and not mic-muted; silence alone does not release it |
| Alias | Alternate identifying text for a port; not a different endpoint |
| Call | Send the calling source to a port, group, conference or IFB according to the function |
| Conference | Shared conversation with a listening return and self-contribution excluded from that return |
| Destination | Where a route sends audio |
| Dim | Reduce program level while an IFB interruption is open; cut removes program instead |
| Function | Action attached to a trigger, such as Call to conference or Listen to |
| Gain | Change to the strength of an audio contribution, expressed in dB |
| Gateway | Host service serving the apps, saving the show and coordinating connections |
| Group | Named set of station/output destinations called together |
| IFB | Program feed to a destination that can be interrupted, with program dimmed or cut |
| In use | Hardware channel selected to become an available audio port |
| Incoming | View of routes owned by other ports that reach this port |
| Key | One of six configurable station controls, or its special Reply control |
| Label | Short display text intended for compact controls |
| LAN | Local network connecting host, operators and nodes |
| Listen to | Function bringing another source into the owner’s listening mix |
| Master | Station’s overall listening volume |
| Matrix | Derived view of configured routing; cells lead back to owning functions |
| Mic off | Talk’s microphone kill; it does not disconnect the station or mute its listening mix |
| N-1 | A mix excluding the listener’s own contribution, used by conference returns |
| Node | Bridge between an OS audio device and the show’s individual input/output ports |
| On call | Gate responding to qualifying incoming direct/group calls; evaluated without cascading chains |
| Port | Named station, physical input/output, conference, group or IFB |
| Program / PGM | Audio normally heard by a listener, for example a show feed |
| Reply | Return call to the last direct/group caller when that caller can receive audio; a later input-only caller clears the Reply target |
| Route audio | Function routing a chosen source to a chosen destination when the owner’s trigger opens |
| Router / mixer | Host audio process that combines and delivers the active routes |
| Session | One current media connection for a station or node |
| Source | Where a route takes audio from |
| Station | Browser operator role with keys, listening mix and optional PIN |
| Takeover | A new device selecting a station replaces its previous session |
| Trigger | Condition under which its functions become active |
| Trim | Physical input/output gain correction in Manager |
| Vox | Signal-activity gate with a threshold, attack and hang time |

For examples rather than definitions, start with [Ports and names](../concepts/ports-and-names.md) and [Triggers and functions](../concepts/triggers-and-functions.md).
